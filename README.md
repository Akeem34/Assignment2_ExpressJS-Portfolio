## Technologies Used

- Node.js and Express (server and routing)
- EJS (view templates and partials)
- Bootstrap 5 (layout and styling)
- Font Awesome (icons)
- Git and GitHub (version control)
- Render (cloud hosting)

## Pages

- **Home:** introduction and links to the other pages
- **About Me:** bio, figure, and an embedded video
- **Projects:** cards describing the work I have completed
- **Contact Me:** contact details and a contact form layout
